# Implementation status

This repository is a reusable template, not a deployed product.

- Included: React/PWA shell, typed domain/MCP contracts, Supabase migrations, owner JWT/RLS boundary, idempotent/versioned mutation path, draft recovery and local bootstrap.
- Intentionally pending per installation: Auth provider setup, owner record, public HTTPS origin, MCP client registration, storage policy, optional research/messaging/email adapters, backups and deployment.
- Acceptance evidence must be recorded by each installer in their own private runbook. Do not copy personal production evidence into this repository.
